# SHUNYA Arcade (शून्य)

#### "Because 'Zero' was invented in India, and so was this project during free hours."


##  What is This Masterpiece?
Welcome to SHUNYA Arcade — the only arcade you'll find that's more entertaining than your college professor's "real-world" coding examples. This is a full-screen, Obsidian Neon themed gaming console that proves you don't need a ₹2 lakh bootcamp to build something actually cool.
Built with Pure Vanilla JavaScript because:

React was taking longer to load than Swiggy during lunch hour
Tailwind CSS classes were longer than my relatives' advice on marriage
I wanted to prove that "import" is not the only thing developers know

Zero frameworks. Zero BS. Just raw talent and Stack Overflow.
